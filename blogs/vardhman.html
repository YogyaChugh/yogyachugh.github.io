Running a real product for $0 a month

Vardhman Saathi has a phone app, a desktop app and a backend, and it serves 200+ people at once. Here's how it runs without a monthly bill.

Small business, small bill. Zero, actually.

Vardhman Electricals wanted an app for their dealers: upload a purchase bill, earn reward coins called V-Coins, and spend them on gifts and products. Their staff needed a desktop app to check those bills, manage users and keep track of stock. And all of it had to run without a big cloud bill every month.

What I built

Everything lives in one repository, in four parts:

  • The Android app (React Native with Expo). Dealers scan their invoices, check their V-Coin balance and order rewards. It's live on Google Play.
  • The admin desktop app (Electron and React). Staff use it to verify bills, manage users and handle inventory.
  • The website (React and Vite), with the public pages, privacy policy and terms.
  • The backend: a PostgreSQL database and server functions on Supabase, plus a few small Cloudflare Workers.

Why the bill is $0

Update, October 2026: when I first wrote this, the backend was a TypeScript API (built with Hono) on Render, and it cost $7 a month. I've since moved it to Supabase Edge Functions, so the whole product now runs on free tiers.

Here's where each piece lives:

  • Supabase holds the PostgreSQL database and runs the server code as Edge Functions. Row Level Security lets the database itself decide who can read what, so there's less permission code for me to maintain.
  • Cloudflare R2 stores the photos and the desktop installer. R2 doesn't charge for downloads, which is usually where storage costs get out of hand.
  • Cloudflare Workers optimise photos and protect the installer download.
  • Cloudflare Pages hosts the website.
You don't need a data center. You need the right architecture.

Shipping without touching a server

Every push to the main branch deploys itself through GitHub Actions. Database changes and functions go to Supabase, the workers go to Cloudflare, and a Windows runner builds a fresh installer for the desktop app and uploads it to R2. Cloudflare Pages picks up the website on its own.

The only thing I still build by hand is the Android app, through Expo EAS, so I can test each version before it reaches the Play Store.

Did it hold up?

It serves 200+ people at the same time across the phone app and three admin dashboards, with changes syncing in real time. You can see it at vardhmansaathi.shop.
